# Cabinet

A web app to track you game library, wishlist and backlog. 

Link: **[cabinet22.vercel.app](https://cabinet22.vercel.app)**

---

## Features

**Collection Management**
- Add games to your Cabinet, Backlog, or Wishlist via the RAWG database (500k+ games)
- Mark games as Unplayed, In Progress, Completed, or 100%
- Visual progress bar showing your completion breakdown
- Sort by rating, date added, title, or status
- Filter by status or search by name
- Grid and list view

**Reviews & Ratings**
- Rate games 1–10
- Write long-form reviews in Markdown with live preview
- Reviews render with full formatting — headings, bold, blockquotes, lists

**Social**
- Public profiles with username, bio, and stats
- Follow friends and see their activity in a live feed
- View any public cabinet in read-only mode
- Real-time follow notifications via Supabase Realtime
- Public / private profile toggle

**Auth**
- Email + password login
- Google OAuth
- Per-user data isolation via Supabase Row Level Security

## Privacy Details
Cabinet is a personal, non-commercial hobby project built for friends. We only store your email for account security, alongside your personal game shelves, ratings, and reviews. By default, your collection is private unless you intentionally flip your profile to public. Your data will never be sold or used for tracking. Because this runs on a personal hobby budget, there are no uptime guarantees or official SLAs. Enjoy!
